### 项目概述
*一个基于springboot的宠物领养管理系统*
### 开发环境
|工具|版本|
|-|-|
|os|Windows 10|
|jdk|1.8|
|IDE|IntelliJ IDEA 2020.2|
|Boostrap|4|
|MySql|8.0.26|
|Maven|3.9.0

### 功能介绍
- 用户可以注册登录修改个人资料，在网站上进行宠物的领养申请操作
- 管理员可以登录后台对用户.宠物的信息进行操作。同时对申请的领养信息进行审批。
